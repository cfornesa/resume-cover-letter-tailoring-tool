# Design system

The application is a React/Vite client with a Node.js/Express backend.
Keep the initial skeleton focused on clear workflow areas and accessible
states; do not introduce product behavior until its GitHub issue is groomed.

- Use the existing artifact theme and shared UI primitives.
- Preserve keyboard access, visible focus states, and semantic labels.
- Prefer reusable components over page-specific duplication.
- Keep loading, empty, and error states explicit.
